# FengShui-Energy-Field
A computational framework for modeling, analyzing, and visualizing Feng Shui energy fields based on spatial orientation, Five Elements, and environmental parameters.

## Modules

| 模块 | 说明 |
|---|---|
| [`玄空飞星/`](玄空飞星/) | **三元玄空飞星排盘**：坐向度数 → 九宫飞星盘（下卦 + 替卦起星），含万年历流年月日时飞星、命卦查询与八宅明镜（游年四吉四凶），并标注玄空与八宅两派的一致处与分歧处；含户型缺角分析（井字法覆盖率 × 旺位/吉方交叉判断）。附单文件可交互网页、算法规格文档、216 组基准数据与 1113 条一致性测试。 |
