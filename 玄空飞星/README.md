# 玄空飞星盘 · Xuan Kong Flying Star

交互式**三元玄空飞星排盘**网页：拖动罗盘定坐向，自动排九宫飞星（**下卦 + 替卦起星**），
附万年历（流年/流月/流日/流时飞星）与命卦查询。单文件、零依赖，直接用浏览器打开即可。

> 灵感来自抖音上一个玄空排盘产品演示，本仓库把排盘规则从零实现并**与专业排盘程序逐格校验**。

## 在线体验

- **网页**：打开 [`玄空飞星排盘.html`](玄空飞星排盘.html)（双击或拖进浏览器）

## 功能

- **可拖动罗盘** —— 二十四山定位盘，拖红线或输入向首度数定坐向；
  内环可切换 **八宫 / 后天八卦 / 先天八卦 / 洛书 / 河图** 五层
- **盘面方位罗盘** —— 九宫盘可切上南下北（传统）或上北下南（地图），
  旁附小罗盘随之翻转并标明左右东西，避免两种取向混淆
- **外环境立极尺** —— 对着在线地图或上传的卫星截图量房屋朝向轴，直读向首度数与二十四山；
  地图不可用时（如 Artifact 版受 CSP 限制）自动提示改用上传底图，功能不受影响
- **实景罗盘（陀螺仪）** —— 手机贴墙实测坐向：iOS 走 `webkitCompassHeading`（真北），
  安卓走绝对朝向（磁北）并提供磁偏角修正滑杆，读数可一键锁定为向首
- **下卦 / 替卦** —— 偏离山中心 ≤ ±4.5° 走下卦，超出走替卦起星（替星口诀）
- **九宫飞星** —— 自动排山星 / 向星 / 运盘 / 流年四层，颜色标当运（旺）、生气、五黄二黑
- **格局判定** —— 旺山旺向 / 双星到向 / 双星到坐 / 上山下水，附顺逆与起星依据
- **万年历** —— 自算节气定四柱，出流年 / 流月 / 流日 / 流时飞星（含遁局、立春时刻）
- **八字命书** —— 四柱、十神、藏干、五行加权、十步大运（起运按「距节天数 ÷ 3」实算），
  含**真太阳时校正**（经度时差 + 均时差，跨日自动重排四柱）；
  另有**流年细盘**（逐年十神、星运、自坐）与**纳音、神煞、旬空**；
  神煞由三合局阳干的十二长生推出（桃花＝沐浴、将星＝帝旺、华盖＝墓、驿马＝长生之冲），非查表；
  四柱与大运干支已与 xunq.chat 命书比对一致
- **八字合盘** —— 两造四柱逐柱比对：天干五合、地支六合／三合／六冲／六害／相刑，
  日主互视十神、配偶宫（日支）关系与五行互补。关系判定由索引算术推出并与传世表反向校验
- **命卦查询** —— 公历年份 → 生肖 + 男 / 女命卦、东西四命
- **八宅明镜** —— 坐山定宅卦，游年变爻推四吉四凶方，叠加在九宫盘上；命卦与宅卦东西四命匹配
- **AI 堪舆师** —— 把已校验的盘面数据交给 Claude 解读（模型只翻译、不重算命理数字）；
  需自建 Serverless 后端，见 [`api/`](api/)。未配置时面板自动禁用，其余功能不受影响
- **玄空 × 八宅交叉** —— 标出两派同吉 / 同凶的方位，并如实列出分歧处（不替你裁决）
- **户型图上传识别** —— 上传户型图自动描出轮廓：Otsu 自适应阈值 + 形态学闭运算封门洞
  （封闭半径按实心度自动搜索）+ Moore 边界追踪 + Douglas–Peucker 简化；底图半透明叠底供核对，
  识别仅作**预标注**，可拖红点手动修正
- **户型缺角分析** —— 可拖点编辑户型轮廓，**井字法 / 中心放射法**两派可切换，按面积覆盖率判缺角；
  再与玄空旺位、八宅吉方交叉，判断这个缺角到底要不要紧（缺在旺位才是真问题，缺在凶位反而无妨）
- **移动端可用** —— 罗盘拖动、户型拖点、3D 单指旋转 + 双指缩放均已在触摸模拟下实测
- **明暗双主题**，响应式，配色取自实物罗盘（黑漆盘面、黄铜刻环、朱砂坐向线）

## 站点

`site/` 是可直接部署的静态站点（门户星图 + 七个工具，统一导航，英文路径）。
部署方式见 [site/DEPLOY.md](site/DEPLOY.md)；仓库根部已备好 GitHub Pages workflow。

**`site/` 由脚本生成，不要手改**——源文件用中文名便于本机阅读，发布副本用 ASCII 名避免 URL 编码：

```bash
python3 build_site.py            # 重新生成 site/，并把导航同步回源文件
python3 build_site.py --check    # 只报不同步，不写盘（供 CI 用）
```

此前 `site/` 是手工维护的，规则逐文件不一致：`外环境立极尺.html` 的导航停在 5 项、
`八字命书.html` 6 项、`炁流场3D.html` 连 `nav.site` 样式都没有。改脚本生成后不再有这类漂移。

## 已知边界

- **下卦 / 替卦分界**取 ±4.5°（各派有 ±3° / ±6°，属流派差异，非对错，可改一个常数）
- **替卦起星**用「口诀派」（3/4/8 亦替，5 廉贞无替）；若你的流派用「文曲无替用本卦」，改 `tiEntry` 即可
- **未做磁偏角修正**：坐向若来自地图方位角需自行校正，实测请以实体罗盘为准
- **缺角阈值 60%** 为经验值，非古法定数；两派分宫法结论会有差异（本工具两派都给，不替你裁决）
- 户型需按**上北下南**绘制（与立极尺/地图取向一致）
- **时刻按北京时间（UTC+8）解算**，异地使用需先换算。此坑实测有产品踩中：xunq.chat 的 /kanyu/ 与 /xunqi/ 两个模块对同一时刻给出不同时柱（乙未 vs 己丑），即一处用北京时间、一处用浏览器本地时间

- **紫白流日用「超神接气」取最近甲子为符头**（可在至日之前＝超神、之后＝接气）。
  另有流派用「至日后第一个甲子」，两者可差到 54 天，流日会整体不同 —— 属流派差异，非对错
- **流日在冬至/夏至处必然跳变**：换遁局即换锚点，不是连续序列。这是定义使然，不是缺陷
- **炁流场测地距离已改用 Dijkstra**：原用先进先出队列做 BFS，但边权有 1（正交）
  与 √2（对角）两种，FIFO 只在等权图上给出最短路。实测它系统性高估距离 ——
  全开放网格与闭式八方距离 `max+(√2−1)·min` 相比最大偏离 9.108 个格距，
  各宫炁强度因此偏了最多 4.5 个百分点。现已精确
- **各宫炁强度只是「自炁口的测地可达性」**，即 `exp(−测地距离/λ)` 的宫内均值，
  λ 取最远距离的 1/2.2。它不含通风、采光、家具与实际气流物理，**不是流体模拟**；
  三维粒子只作观感，不参与统计
- **节气解算已升级**：原用 Meeus 低精度太阳黄经，与高精度式比对，1950–2050 的
  2424 个节气平均差 3.65 分、最大 13.1 分 —— 约 0.017% 的出生时刻会因此判错月柱，
  立春处最大 11.7 分、会连年柱一起改。现改用截断 VSOP87D + ΔT，与公开历书
  21 个节气日期全同、时刻均在 ±2 分内
- **ΔT 用 Espenak–Meeus 多项式**：其 2005–2050 段是预测值，对 2024 年给 73.9 秒、
  实测约 69.2 秒，高估约 4.7 秒（= 0.08 分钟），对节气时刻无实际影响
- **天时为天文近似式**：月相未计月球轨道摄动，月龄精度 ±0.5 天；日出日落用 NOAA 简化式，
  实测偏差约 ±5 分钟（北京 2026-08-20 得 05:32/19:07，年历为 05:37/19:00）。够用于择时参考，**不可当年历**
- **潮汐只是日月起潮力的相对强度**，不含地形、水深、风与气压——不是实际潮高，沿海作业请查潮汐表

- **六爻只装卦，不断卦**：取用神、旺衰、应期属术家判断，流派分歧大，本工具不代为裁决
- **起卦用铜钱法**（背 3 字 2，和 6/7/8/9 → 老阴/少阳/少阴/老阳），动爻概率 1/4；
  古法揲蓍的四象概率不同（3/16、5/16、7/16、1/16），两法卦象分布有别，请勿混用

传统文化学习与参考用途，不替代专业勘察。
