## 1. 输入 / 输出契约

```
输入:  yun         int    元运 1-9
       facing_deg  float  向首方位角，正北=0°，顺时针，[0,360)
输出:  {坐山, 向首, 卦法, 山星入中, 山星飞法, 向星入中, 向星飞法,
        运盘{9宫}, 山星盘{9宫}, 向星盘{9宫}, 格局}
```

**度数约定**：输入的是 **向**（facing / 朝向）的方位角，不是坐山。
坐山 = `(facing_deg + 180) mod 360`。视频中那套 App 用的也是这个约定（209.5° → 丑山未向）。

## 2. 常量表

### 2.1 洛书飞泊路径（顺飞）

```
中(5) → 乾/西北(6) → 兑/西(7) → 艮/东北(8) → 离/南(9)
     → 坎/北(1) → 坤/西南(2) → 震/东(3) → 巽/东南(4)
```

顺飞 = 沿此宫序数字 +1；逆飞 = **同一宫序**，数字 −1。逆飞不是把宫序倒过来走。
（这是常见实现 bug：把路径反转而不是把步长取负，结果 8 宫全错、只有中宫对。）

### 2.2 二十四山（每山 15°，自壬 345° 起）

| 宫 | 地元龙 | 天元龙 | 人元龙 |
|---|---|---|---|
| 坎(1) 北 | 壬 **阳** 345° | 子 **阴** 0° | 癸 **阴** 15° |
| 艮(8) 东北 | 丑 **阴** 30° | 艮 **阳** 45° | 寅 **阳** 60° |
| 震(3) 东 | 甲 **阳** 75° | 卯 **阴** 90° | 乙 **阴** 105° |
| 巽(4) 东南 | 辰 **阴** 120° | 巽 **阳** 135° | 巳 **阳** 150° |
| 离(9) 南 | 丙 **阳** 165° | 午 **阴** 180° | 丁 **阴** 195° |
| 坤(2) 西南 | 未 **阴** 210° | 坤 **阳** 225° | 申 **阳** 240° |
| 兑(7) 西 | 庚 **阳** 255° | 酉 **阴** 270° | 辛 **阴** 285° |
| 乾(6) 西北 | 戌 **阴** 300° | 乾 **阳** 315° | 亥 **阳** 330° |

规律：地元龙「阳阴阳阴阳阴阳阴」，天元/人元龙「阴阳阴阳阴阳阴阳」。

## 3. 排盘算法

```
1. 定山向
   向首 = mountain_of(facing_deg)
   坐山 = mountain_of(facing_deg + 180)

2. 运盘
   运盘 = fly(yun, 顺飞)                     # 元运数入中，恒顺飞

3. 山星
   山星入中 = 运盘[坐山.宫]
   顺逆     = 阴阳_of(山星入中, anchor=坐山)
   山星盘   = fly(山星入中, 顺逆)

4. 向星
   向星入中 = 运盘[向首.宫]
   顺逆     = 阴阳_of(向星入中, anchor=向首)
   向星盘   = fly(向星入中, 顺逆)
```

### 3.1 顺逆判定（核心，也是最容易写错的一步）

```
阴阳_of(entry_star, anchor):
    if entry_star == 5:
        return anchor 本山之阴阳           # 5 无本宫，见 §6 约定 A
    宫 = entry_star                        # 星数即其本宫洛书数
    山 = 该宫中与 anchor 同三元龙的那一山
    return 山.阴阳
阳 → 顺飞, 阴 → 逆飞
```

**注意**：山星和向星的顺逆是**各自独立**判定的，取决于「入中星所属宫里、与坐山/向首同元龙的那一山」的阴阳，**不是**直接看坐山/向首自己的阴阳。skill 文件里那张「阳山阳向→山逆向顺」的四行表是杜撰的，见 §5.2。

### 3.2 格局判定

令当运星 = `yun`：

| 条件 | 格局 |
|---|---|
| 山星盘[坐山宫]==yun 且 向星盘[向首宫]==yun | 旺山旺向 |
| 山星盘[向首宫]==yun 且 向星盘[向首宫]==yun | 双星到向 |
| 山星盘[坐山宫]==yun 且 向星盘[坐山宫]==yun | 双星到坐 |
| 山星盘[向首宫]==yun 且 向星盘[坐山宫]==yun | 上山下水 |

### 3.3 流年中宫

```
liunian_center(year) = (7 - 1 - (year - 1984)) mod 9 + 1
```
下元甲子 1984 = 七赤入中，逐年逆行。流年盘一律顺飞。

| 向星入中·飞法 | 6 入中·逆飞 | 6 入中·逆飞 | ✅ |
| 运盘 9 宫 | 8/4/6 7/9/2 3/5/1 | 同 | ✅ |

## 5. 勘误：`fengshui.skill/references/feixing.md` 的错误

装这个 skill 可以，但**不要拿它的数据当事实**。以下五处必须覆盖：

### 5.1 二十四山阴阳（严重）

skill 写的是「阳山：子寅辰午申戌 / 阴山：丑卯巳未酉亥」—— 这是**地支的阴阳**，不是玄空二十四山的阴阳。

- 12 地支里判错 6 个：**子、辰、巳、午、戌、亥**
- 另外 12 山（壬癸甲乙丙丁庚辛 + 乾坤艮巽）**完全没收录**

按它的表算，丑山未向的向星会变成「6 入中顺飞」，与 App 实测的逆飞相反，整个向星盘 8 宫全错。

### 5.2 顺逆判定表（严重）

skill 的「坐山阴阳 × 立向阴阳 → 山星/向星顺逆」四行表不成立。真实规则见 §3.1，
顺逆由**入中星所属宫的同元龙山**决定，与坐山/向首自身阴阳没有直接关系。

### 5.3 九运坐向格局（四条全错）

| 坐向 | skill 声称 | 实算 |
|---|---|---|
| 午山子向 | 旺山旺向 | **双星到向** |
| 子山午向 | 上山下水 | **双星到坐** |
| 卯山酉向 | 双星到向 | **双星到坐** |
| 酉山卯向 | 双星到坐 | **双星到向** |

九运根本不存在旺山旺向和上山下水局，前两条的格局名不可能出现；后两条是把一对坐向写反了。

### 5.4 流年中宫表整体偏移一年

| 年份 | skill | 实际 |
|---|---|---|
| 2024 | 4 | **3** |
| 2025 | 3 | **2** |
| 2026 | 2 | **1** |
| 2027 | 1 | **9** |

skill 表内部是自洽的，但整张表的年份标签比实际早了一年（它的「2024 行」其实是 2023 的盘）。
App 实测 2026 丙午年中宫 = 1 白，与修正值一致。

## 7. 替卦（起星）算法 —— 已验证

**触发**：向首偏离山中心 > ±4.5°（约定 B）时用替卦，否则下卦。

**替星口诀**（山名 → 替星，恒 ∈ {1,2,6,7,9}）：

```
子癸甲申            → 1 贪狼
壬卯乙未坤          → 2 巨门
乾亥辰巽巳戌        → 6 武曲
酉辛丑艮丙          → 7 破军
寅午庚丁            → 9 右弼
```

（4+5+6+5+4 = 24 山，无重无漏。）

**入中之数**（山盘、向盘各自独立求）：

```
tiEntry(anchor):                 # anchor = 坐山(求山盘) 或 向首(求向盘)
    R = 运盘[anchor.宫]           # 即下卦时的入中运星
    if R == 5:  return 5          # 廉贞入中无替，仍用 5
    M = R 本宫中与 anchor 同三元龙 的那一山
    return 替星口诀[M]
```

**顺逆**：与下卦**完全相同** —— 由下卦入中运星 R 经 §3.1 判定，替卦只改「入中之数」，**不改飞行方向**。

**关键点**：替星查的是 `R 的本宫 + anchor 的元龙` 那一山，**不是** anchor 自己的字。
例：辛山乙向，运盘[坐山兑]=2 → 2 本宫为坤 → 坐山辛属人元 → 坤宫人元=申 → 申替星=1，故山星 1 入中。

**校验**：与专业排盘程序【妙訣堂】逐格对齐 ——

| 案例 | 中宫入中 | 全盘 18 星 |
|---|---|---|
| 九运 辛山乙向兼戌辰 | 山 1 顺 / 向 7 逆 | ✅ 全同 |
| 九运 子山午向兼壬丙 | 山 5 逆 / 向 6 顺 | ✅ 全同 |

第二例专测边界：山星 R=5（廉贞→留 5）、向星 R=4（文曲→替 6）。
可见【妙訣堂】用**口诀派**（3/4/8 亦替），非「文曲无替用本卦」派 —— 若你的流派用后者，改 `tiEntry` 即可。

## 8. 户型九宫覆盖（缺角判定）

**井字法**：取户型外接矩形，均分 3×3。上北下南绘制，故

```
row0(北)  西北6  北1   东北8
row1      西7    中5   东3
row2(南)  西南2  南9   东南4
```

每宫覆盖率 = `area(户型多边形 ∩ 该格) / area(该格)`，
用 Sutherland–Hodgman 对轴对齐矩形裁剪 + 鞋带公式求面积。

**判定**：覆盖率 < 60% 记为缺角。**该阈值是经验值，非古法定数**，可调。

**交叉判断**（这一层才是重点）—— 缺角要不要紧，取决于缺在什么位置：

| 缺角所在 | 判定 |
|---|---|
| 玄空当运旺星 + 八宅四吉 | 影响最大：最该用的位置被削掉 |
| 玄空当运旺星 | 影响较大：旺气无处落 |
| 八宅四吉 | 影响中等：宅命层面的好位置用不上 |
| 玄空凶星 / 八宅四凶 | **影响不大**：本为凶位，缺角反而少受其害 |

**验证**：方正户型九宫全 100%；L 形缺左下 → 西南宫 0%、余宫 100%；
方正 / L 形 / 三角三例均满足**九宫裁剪面积之和 = 原多边形面积**（精确守恒）。

**已知简化**：立极点取外接矩形中心，非面积形心；凹形户型两者会有偏差。
另有「中心放射法」（自立极点作 8 个 45° 扇区）流派，结论与井字法不同，本工具未实现。
